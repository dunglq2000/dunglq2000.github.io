dunglq2000.github.io
####################

Mã nguồn landing page nằm trong ``site-src``. Build và đồng bộ toàn bộ các site
bằng lệnh:

.. code-block:: console

   ./publish.sh

Bốn notebook được publish tại ``mathematics``, ``contests``, ``cryptography``
và ``game-programming``. Mỗi thư mục chứa nội dung từ ``_build/html`` của
project tương ứng.
